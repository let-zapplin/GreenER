Natural Earth — Land, escala 1:110m (domínio público).

O SDK MapTiler renderiza esses dados locais como um globo 3D sem depender
de uma chave do MapTiler Cloud. A variável VITE_MAPTILER_API_KEY é opcional
e, quando preenchida, seleciona o mapa de satélite do MapTiler.
